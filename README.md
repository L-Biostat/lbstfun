# lbstfun

<!-- badges: start -->

<!-- badges: end -->

Collection of functions to help reporting for L-BioStat statistical analysis report created using R.

## Installation

You can install the development version of lbstfun from [GitHub](https://github.com/) with:

``` r
devtools::install_github("L-Biostat/lbstfun")
```

## List of functions

| Name | Description | Keyword |
|----|----|----|
| `fmt_pvalue()` | Format a column containing p-values in a gt table | gt |
| `tab_bold_headers()` | Make all headers bold in a gt table | gt |
