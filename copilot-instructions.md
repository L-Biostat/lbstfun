# Copilot Instructions for lbstfun

## What This Package Does

`lbstfun` is an R utility package for L-BioStat statistical reporting.
It wraps the [`gt`](https://gt.rstudio.com/) package to provide helper
functions for formatting p-values and applying bold styling to table
headers and significant results.

The package also ships two statistical analysis vignettes (cLDA and ITS)
and an example dataset (`priority`) from a longitudinal trial.

## Build, Test, and Document Commands

All commands run from an R console with the working directory set to the
package root:

``` r
# Load package for interactive development
devtools::load_all()

# Regenerate documentation from roxygen2 comments (updates man/ and NAMESPACE)
devtools::document()

# Run full test suite
devtools::test()

# Run a single test file
testthat::test_file("tests/testthat/test-fmt_pvalue.R")

# Full R CMD CHECK (run before any release)
devtools::check()

# Build pkgdown documentation site
pkgdown::build_site()
```

## Architecture

Three exported functions, each in its own file under `R/`:

| File                   | Function                                                                                  | Purpose                                                                                                                     |
|------------------------|-------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| `R/fmt_pvalue.R`       | [`fmt_pvalue()`](https://l-biostat.github.io/lbstfun/reference/fmt_pvalue.md)             | Format p-value columns in a `gt` table via [`scales::label_pvalue()`](https://scales.r-lib.org/reference/label_pvalue.html) |
| `R/tab_bold_headers.R` | [`tab_bold_headers()`](https://l-biostat.github.io/lbstfun/reference/tab_bold_headers.md) | Bold column headers (and optionally spanner headers)                                                                        |
| `R/tab_bold_pvalues.R` | [`tab_bold_pvalues()`](https://l-biostat.github.io/lbstfun/reference/tab_bold_pvalues.md) | Bold rows where a p-value column falls at or below a threshold                                                              |

All functions follow the same pattern: accept a `gt_tbl` object as the
first argument and return a modified `gt_tbl`, making them
pipe-friendly.

Example dataset `priority` (longitudinal trial data) lives in `data/`
and is generated by `data-raw/priority.R` from a SAS source file.

## Key Conventions

### One file per exported function

Each exported function has exactly one corresponding `R/<function>.R`
file and one `tests/testthat/test-<function>.R` file.

### Documentation is roxygen2

All function docs use `#'` roxygen2 comments. Use `@inheritParams` when
a function shares parameters with another (e.g., inheriting `data`,
`columns`, `rows` from `fmt_pvalue`). Run `devtools::document()` after
any documentation change — never edit `man/` files directly.

### Tidy evaluation with `{{}}`

Functions that accept unquoted column names use the `{{}}` (embrace)
operator from `rlang`. The `column` argument in
[`tab_bold_pvalues()`](https://l-biostat.github.io/lbstfun/reference/tab_bold_pvalues.md)
is the canonical example.

### Native pipe

Use the native R pipe `|>` (R 4.1+), not `%>%`.

### Snake_case everywhere

Function names and arguments use `snake_case` (e.g., `tab_bold_headers`,
`add_p`, `accuracy`).

### Test structure

Tests extract the internal `tbl$_styles` list from a rendered gt table
to verify that styling was applied to the correct rows/columns. Follow
this pattern when adding tests for new styling functions.

### Dependencies

Only add to `Imports` in `DESCRIPTION` if a package is used in exported
functions. Packages used only in vignettes or tests belong in
`Suggests`.
