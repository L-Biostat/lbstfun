# Example data set for cLDA

An example dataset coming from a study called PRIORITY (hence the name)
to illustrate how to fit and analyze results from a constrained
longitudinal data analysis (cLDA) in R.

## Usage

``` r
priority
```

## Format

\`priority\` A data frame with 807 rows and 4 columns:

- id:

  Patient id

- trt:

  Treatement group, 1 or 2 for placebo or treatement

- time:

  Time points of the study where data was collected (0, 1, or 2)

- outcome:

  The outcome to analyze
